# 2026 单词王 · 大班级 —— 练习网页

由《2026单词王大赛（大班级）题库.pdf》生成。纯静态页面，解压后双击 `index.html` 就能用，不用装任何东西、不需要联网。

## 怎么打开

| 方式 | 做法 |
|---|---|
| 电脑 | 解压后双击 `index.html`，用 Chrome / Edge / Safari 都可以 |
| 手机 | 把整个文件夹传到手机后用浏览器打开，或用 `python -m http.server` 起个本地服务 |

## 发音

**一条过的预生成录音**（英文女声 `English_Graceful_Lady`，speed 0.9）：

- 一次 TTS 调用把 134 词拼成一条 2.5 MB / 157 秒的长 mp3，用 **逗号** 做词间分隔
- 浏览器首屏 `decodeAudioData` 后跑静音切分（25ms RMS / 300ms 静音阈值 / 自动阈值）拿到 134 个时间戳，切分结果本地缓存到 `localStorage`（后续打开直接用）
- 点哪个词就用 `AudioBufferSourceNode.start(when, offset, duration)` 切播对应的段，不重复拉文件
- 所有设备发音完全一致，不会被系统音色带偏；**断网也能用**
- 「慢速发音」开关用 `playbackRate=0.6` 实现，放慢**不变调**
- 万一浏览器解码失败或某词边界没切到，会自动回退到该词自己的小 mp3（`audio/wNNN.mp3`，作为兜底音轨一并打包）

## 两种模式，五种玩法

首页顶部两个大按钮分流：

### 🎮 练习模式（4 种子玩法）
- **看图选词**（推荐，和"看图认词"的比赛形式一致）：给图片，选英文单词
- **听音选图**：播英文，从 4 张图里选
- **看词选图**：给英文单词，选图片
- **单词闪卡**：一词一卡，点一下翻面看单词

练习不限时，错了能重看，错题进错题本，影响掌握度曲线。

### 📝 考试模式（严格单题型）
- 题型固定 **「看图选词」**（和"看图认词"比赛完全一致）
- 题数 10 / 20 / 30 / 全部 134 题可选
- 每题 **30 秒**圆环倒计时，超时自动按错计
- 答题后立即显示对错，**1.5 秒后自动进下一题**（不点"下一题"，强制流速）
- 考试不进入错题本、不影响练习掌握度（"考分"和"学习曲线"互不污染）
- 结束看 **评分卡**（A / B / C / D）：≥90% A · ≥80% B · ≥60% C · 其余 D
- 「查看错题」可重听每题发音、对比你的答案

## 按章节练习

练习屏顶部有「📦 全部 134」/「🗂 按章节」二选一段控件：

- **📦 全部 134**：从全部词随机抽题，每轮默认 10 题
- **🗂 按章节**：切到 15 个主题网格（衣物 5 / 水果 13 / 动物 22 / 身体 10 / 动作 9 / 食物 12 / 感受 10 / 数字 3 / 家人 8 / 家居 6 / 玩具 12 / 颜色 7 / 自然 6 / 交通 7 / 餐具 4）
- 点主题卡 → 自动切回"全部 134"视图（已选池在背后生效），4 种子玩法都按当前章节抽题
- 章节池子太小（数字 3、餐具 4）时，系统会从全词表借 distractor 凑齐 4 个不重复选项，不会有「两个 eight」这种重复贴

## 设置项

- **显示中文**：显示/隐藏中文释义
- **自动朗读题目**：出题时自动念
- **计时闯关**：60 秒倒计时，答对得分带连击和剩余时间加成
- **慢速发音（跟读）**：录音放慢到 0.6 倍
- **每轮题数**：10 / 20 / 30 题，选了会记住（也可以在网址后加 `?n=20` 临时改）

## 小技巧

- 网址后面加 `?n=20` 可以把每轮题数改成 20（默认 10，最大 200），例如 `index.html?n=30`
- 练习记录存在本机浏览器里（localStorage），换设备不同步；首页可以看掌握度、错题本，也可以一键清空

## 文件说明

```
index.html   页面结构
style.css    样式
app.js       全部逻辑（播放、判题、计时、进度）
data.js      134 个词条数据（内联，双击打开也能用）
words.json   同一份数据的 JSON 版，方便二次开发
img/         134 张单词图，从题库 PDF 里逐张抠出来的
audio/
  all-words.mp3   一条过、157 秒的长录音（主路径，发声解码 + 自动切分）
  w001.mp3 ... w134.mp3   每词独立的录音（兜底路径，主路径失败时自动回退）
README.md    本文件
```

图片取自题库 PDF 原图，200 DPI 渲染后裁切、压到 440px JPEG，共约 1.7 MB。
主音频 `audio/all-words.mp3` 2.5 MB，由 Matrix TTS（音色 `English_Graceful_Lady`，speed 0.9）一条过生成。
兜底 `audio/wNNN.mp3` 134 段共约 2.5 MB，同音色、同样参数、逐词合成。
整个文件夹约 6.5 MB。

## 重新生成（需要时）

```bash
python tools/extract_cards.py    # 从 PDF 重新抠图 -> _cards_raw.json
python tools/build_words.py      # 生成 words.json / data.js / img/
python tools/gen_audio.py        # 一条过生成 audio/all-words.mp3（首选）
python tools/gen_audio.py --per-word   # 逐词生成 audio/wNNN.mp3（兜底）
```
